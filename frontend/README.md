# Frontend 语言学习区

本目录只包含 JavaScript、TypeScript 与浏览器 Web API 的语言和运行时案例；Vue、React 等框架学习不放入这里。

## 推荐顺序

JavaScript `es-module-demo` → `closure-prototype-demo` → `prototype-chain-demo` → `promise-async-demo` → Web API `event-loop-demo`/`fetch-abort-demo`/`dom-event-demo` → TypeScript `type-system-generics-demo`/`utility-type-demo`/`decorator-demo`/`advanced-type-demo`。

JavaScript/Web API 案例使用 Node 22 的内置测试运行器；TypeScript 案例使用独立 `pnpm` 工程和 `tsc --noEmit`。

完整前置/后续关系见 [`docs/learning-case-catalog.md`](../docs/learning-case-catalog.md)。
