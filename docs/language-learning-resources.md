# 语言学习资源推荐

星级含义：★★★★★ = 长期主线资源；★★★★☆ = 高质量补充；★★★☆☆ = 针对特定主题或快速查阅。链接尽量选择规范、官方教程、活跃开源项目和长期维护博客。

| 主题 | 资源 | 星级 | 推荐理由 |
| --- | --- | --- | --- |
| Python | [官方 Tutorial](https://docs.python.org/3/tutorial/) | ★★★★★ | 与解释器版本同步，适合作为主线 |
| Python | [Real Python](https://realpython.com/) | ★★★★☆ | 文章和练习贴近实际，适合补背景 |
| Python | [Fluent Python 代码仓库](https://github.com/fluentpython) | ★★★★☆ | 深入数据模型、迭代器和并发；只学习语言章节 |
| Rust | [The Rust Programming Language](https://doc.rust-lang.org/book/) | ★★★★★ | 所有权和类型系统的官方完整路径 |
| Rust | [Rustlings](https://github.com/rust-lang/rustlings) | ★★★★★ | 小练习驱动，适合配合本仓库 Demo |
| Rust | [Comprehensive Rust](https://google.github.io/comprehensive-rust/) | ★★★★☆ | Google 的结构化课程，适合系统复习 |
| JavaScript | [MDN JavaScript Guide](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide) | ★★★★★ | 标准 API 与浏览器语境兼顾 |
| JavaScript | [javascript.info](https://javascript.info/) | ★★★★☆ | 对事件循环、模块、Promise 的解释直观 |
| JavaScript | [You Don't Know JS Yet](https://github.com/getify/You-Dont-Know-JS) | ★★★★★ | 深入闭包、作用域和对象模型，适合进阶 |
| TypeScript | [TypeScript Handbook](https://www.typescriptlang.org/docs/handbook/intro.html) | ★★★★★ | 类型系统的权威入门与参考 |
| TypeScript | [Type Challenges](https://github.com/type-challenges/type-challenges) | ★★★★☆ | 通过题目强化泛型和条件类型 |
| Web API | [WHATWG HTML Standard](https://html.spec.whatwg.org/) | ★★★★★ | Event Loop 等浏览器语义的规范来源 |
| Web API | [web.dev](https://web.dev/) | ★★★★☆ | 性能、Fetch 和平台能力的实践文章 |
| JVM/Java | [OpenJDK JEP Index](https://openjdk.org/jeps/0) | ★★★★★ | 版本演进和预览能力的事实依据 |
| JVM/Java | [Baeldung](https://www.baeldung.com/) | ★★★★☆ | Java/JVM 示例丰富，适合作为社区补充而非规范来源 |
| Go | [Go Tour](https://go.dev/tour/) | ★★★★★ | 官方交互式入口，适合按 Demo 顺序实践 |
| Go | [Effective Go](https://go.dev/doc/effective_go) | ★★★★★ | 解释 Go 的惯用设计和错误处理风格 |
| Go | [Go by Example](https://gobyexample.com/) | ★★★★☆ | 小例子覆盖并发、泛型和标准库，适合快速对照 |
| C | [cppreference C](https://en.cppreference.com/w/c) | ★★★★★ | 标准库和语言规则查阅入口 |
| C | [SEI CERT C](https://wiki.sei.cmu.edu/confluence/display/c) | ★★★★★ | 指针、字符串和安全边界的实践规则 |
| C | [Beej's Guide to C](https://beej.us/guide/bgc/) | ★★★★☆ | 适合从基础到指针的连贯阅读 |

## 推荐使用方法

先以官方教程建立概念，再用本仓库 Demo 运行和修改，最后选一个社区资源理解常见误区。遇到版本差异时以语言规范、官方 API 文档和对应 JEP 为准。
