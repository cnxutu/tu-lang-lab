# Frontend 语言与 Web API 学习地图

| 状态 | 能力 | Demo | 适合解决的问题 |
| --- | --- | --- | --- |
| stable | ES Module | [`es-module-demo`](../frontend/javascript/es-module-demo/) | 显式依赖和模块边界 |
| stable | Closure/Object method | [`closure-prototype-demo`](../frontend/javascript/closure-prototype-demo/) | 私有状态与对象行为 |

| stable | Fetch cancellation | [`fetch-abort-demo`](../frontend/web-api/fetch-abort-demo/) | 超时、路由切换和取消 |
| stable | DOM/Event | [`dom-event-demo`](../frontend/web-api/dom-event-demo/) | 页面元素和用户交互 |
| stable | Type System/Generics | [`type-system-generics-demo`](../frontend/typescript/type-system-generics-demo/) | API 结果契约和类型收窄 |
| stable | Utility Types | [`utility-type-demo`](../frontend/typescript/utility-type-demo/) | 安全的部分更新类型 |
| stable | Decorator | [`decorator-demo`](../frontend/typescript/decorator-demo/) | 声明式横切行为 |
| stable | Advanced Types | [`advanced-type-demo`](../frontend/typescript/advanced-type-demo/) | 事件契约和类型映射 |

JavaScript 与 Web API 案例已在 Node 22 验证；TypeScript 案例已通过 TypeScript 5.6 `tsc --noEmit`。
